Pertanyaan FAQ

HTML (HyperText Markup Language) adalah bahasa standar untuk membuat struktur halaman web. HTML sangat penting karena menjadi kerangka dasar yang menentukan bagaimana konten ditampilkan di browser.

CSS dapat dihubungkan ke HTML melalui tiga cara: Inline CSS (atribut style), Internal CSS (tag <style> di dalam <head>), dan External CSS (menggunakan tag <link> ke file .css terpisah).

JavaScript memberikan interaktivitas pada halaman web, seperti validasi, galeri gambar dinamis, dan pembaruan konten

Desain responsif memastikan tampilan website tetap optimal dan mudah digunakan di berbagai ukuran layar, mulai dari smartphone hingga monitor desktop.

Flexbox dirancang untuk tata letak satu dimensi (baris atau kolom), sedangkan CSS Grid dirancang untuk tata letak dua dimensi (baris dan kolom sekaligus).

Gunakan framework CSS saat Anda butuh membangun proyek dengan cepat, butuh konsistensi desain, atau bekerja dalam tim besar dengan standar komponen yang sama.

Browser menyimpan salinan file (gambar, CSS, JS) di perangkat pengguna. Saat pengguna mengunjungi kembali situs, browser memuat file dari cache lokal agar lebih cepat tanpa harus mengunduh ulang dari server.

GET digunakan untuk meminta data dari server dan datanya terlihat di URL. POST digunakan untuk mengirim data ke server (seperti form) dan datanya disembunyikan di dalam body request.

SQL database digunakan untuk menyimpan, mengelola, dan mengambil data terstruktur (relasional) dengan aman dan efisien, yang sangat penting untuk aplikasi web dinamis.
